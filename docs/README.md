# Operational & Skill Documentation (`docs/`)

This directory houses operational reports, security assessment audit trails, cloud cost models, and visual architecture diagram assets generated by agent skills.

## Structure & Artifact Types

- **Architecture Diagrams (`architecture-diagram` skill):**
  - Markdown architecture definitions: `docs/*-architecture.md`
  - Interactive standalone HTML/SVG assets: `docs/*-architecture.html`
- **Security Assessment Reports (`codemender` skill):**
  - Vulnerability Discovery: `docs/codemender-01-vulnerability-scan-report.md`
  - Exploit Verification & Triage: `docs/codemender-02-verification-report.md`
  - Automated Remediation & Patch Diffs: `docs/codemender-03-remediation-report.md`
  - Master Security Audit Summary: `docs/codemender-security-audit-summary.md`
- **Cloud Infrastructure Cost Estimates (`gcp-cost-estimator` skill):**
  - GCP Workload Estimates & BoMs: `docs/gcp_cost_estimate_<project_name>.md`
